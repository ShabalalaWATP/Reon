# Organisation Directory Function Labels

## Purpose

Make the organisation directory describe operational functions in concise,
recognisable language without changing routing, staffing or authorisation data.

## Requirements

1. CRIOC, command and Ops routing units are labelled **Routing**.
2. Staffed delivery units are labelled **Analysis Team**.
3. An unstaffed delivery unit remains visibly identified as **Analysis Team ·
   Awaiting staffing**.
4. The directory summary identifies **QC** as a shared function across the
   hierarchy.
5. The labels do not change organisation identifiers, routing destinations,
   staffing calculations or access decisions.

## Acceptance criteria

- Neither **Routing function** nor **Team staffed** appears in the directory.
- Routing, Analysis Team and QC terminology is visible to authorised staff.
- Existing empty, loading, error and Administrator rename behaviour remains
  unchanged and accessible.
